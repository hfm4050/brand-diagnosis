# 열정덕 카피 변환 프롬프트

수집된 리포스트(`threads/output/reposts.md` 또는 노션 보관함의 원문)를 넣고
아래 프롬프트를 Claude에게 그대로 사용하세요.

---

아래 [원문 목록]은 스레드에서 반응 100개 이상 받은 글들이야. 각 글에 대해:

1. **카테고리 분류** — 다음 중 하나로: 🎯 마케팅·브랜딩 인사이트 / 💼 사업·자영업 현실 /
   🔥 동기부여·마인드셋 / ⏰ 일·습관·자기관리 / 😂 공감·유머 / 🤖 트렌드·AI 활용
2. **후킹 분석** — 이 글이 터진 이유(첫 줄 훅, 반전, 숫자, 공감 포인트)를 한 줄로
3. **열정덕 카피 2버전** — 아래 톤 규칙에 맞춰 새로 작성

## 열정덕 톤 규칙

- 화자: 병원·소상공인 마케팅 현장에서 직접 뛰는 마케터. 이론이 아니라 실전 경험으로 말함
- 솔직하고 에너지 있게, 허세 없이. 실패담도 그대로 공개
- 스레드체: 짧은 문장, 줄바꿈 많이, 담백한 해요체 또는 구어체
- 숫자·사례는 구체적으로 ("매출 3배" 대신 "월 400 → 1,200")

## 작성 규칙

- 원문 문장 재사용 금지 — 후킹 **구조만 차용**, 사례는 열정덕 경험으로 교체
- 첫 줄만 보고 멈추게 만들 것 (첫 줄이 전부다)
- 500자 이내, 한 문단 1~2문장
- 마무리는 질문 또는 단정 한 줄 → 댓글 유도
- 해시태그·이모지 남발 금지 (0~1개)

결과는 카테고리별로 묶어서 표로 정리해줘: 원문 요약 / 반응 수 / 후킹 분석 / 열정덕 카피 v1 / v2
